## ② 문제 (한 화면에 한 문제)

```
 그만하기                        3 / 10
 ■■■□□□□□□□                      ← 진행 막대 (지금 칸 노랑)
          재학생 · 학식 · 편의시설
     율곡기념도서관 안 복사점은 어디에 있을까?
 [ 2층과 4층 ]   ← 고르면 틀린 답 빨강
 [ 지하와 3층 ]  ← 정답 초록
 [ 3층과 4층 ]   (흐리게)
 [ 1층과 2층 ]   (흐리게)
 ┌ 아쉬워요. 정답은 「지하와 3층」 ─────┐
 │ 해설 한두 줄                       │
 │ 출처 · 페이지 (확인 날짜) · 출제자    │
 │           [ 다음 문제 ]            │
 └───────────────────────────────┘
```

- 보기 순서는 매번 섞인다. 정답은 고른 뒤 서버가 알려 준다 (첫 답만 기록)
- O/X 문제는 큰 버튼 두 개

## ④ 문제 내기

난이도 · 분야 · 형식(4지선다 / O·X) · 문제 · 보기와 정답 · **해설(필수)** · **출처(필수)** · 닉네임 → 「올리기」 → "관리자가 확인한 뒤 퀴즈에 나와요"

## ⑤ 관리 (`/admin`)

- 로그인(비밀번호) → 숫자 카드(검수 대기 · 공개 문제 · AI 상태)
- 탭: **검수 대기**(점검 결과 · 근거 문장 · 승인 / 고쳐서 승인 / 반려) · **AI 초안 만들기**(안내문 붙여 넣기) · **직접 추가** · **전체 문제**(삭제)

## 비어 있을 때 · 실패했을 때

- 문제가 없는 버전 → "아직 공개된 문제가 없어요."
- 퀴즈가 2시간 지나 만료 → "퀴즈가 만료됐어요. 처음부터 다시 풀어 주세요."
- 출제 자격 만료(7일) · 위조 → 자격 지우고 "재학생 버전을 다시 풀어 주세요"
- AI 설정 없음 → AI 초안 버튼 누르면 설정 안내, 나머지는 동작
