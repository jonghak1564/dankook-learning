# 02 벤치마킹 — 단국러닝

> 2026-11-23 인터넷 조사 (Claude). 서비스 기능은 앱스토어 · 공식 페이지 · 기사 기준이고, 화면 패턴 중 출처가 없는 것은 「관찰」로 적었다.

## 1. 화면 참고: 대학 커뮤니티 앱(에브리타임)식 구성

**출처로 확인한 것**: 학교별 인증 커뮤니티, 게시판 · 시간표 · 강의평 · 학식 · 셔틀 정보. 2023년 연구에서 주 이용 목적은 학사 · 수업 · 졸업 정보 탐색, 방해 요인은 익명성에서 오는 정보 품질 문제.

**관찰 (출처 없음)**: 흰 카드 + 얇은 회색 구분선, 그림자 거의 없음 / 게시판 이름이 줄로 늘어선 목록 / 글 = 제목 · 미리보기 · 작은 메타 줄 / 댓글은 평평한 목록 / 아래 탭 / 강조색 하나만 아껴 씀.

**단국러닝에 옮긴 것**: 게시판 목록(분야별 퀴즈), 최근 올라온 문제 피드, 문제 = 게시글 · 해설 = 댓글 모양, 아래 탭(홈 · 오답노트 · 문제 올리기).
**가져오지 않은 것**: 이름 · 로고 · 아이콘 · 고유 명칭 · 강조색(빨강). 강조색은 포스터와 같은 단국 남색. "○○ 스타일"이라고 홍보하지 않는다 (상표 혼동).

"고인물 테스트" 형태의 대학 퀴즈 서비스는 검색으로 찾지 못했다 (커뮤니티 밈 · 재미 글 수준) → 틈새.

## 3. 단국러닝 차별점

1. **검증된 학교 정보** — 공식 안내문 → AI 초안 → 관리자 검수, 해설마다 출처. 커뮤니티 "카더라"와 공식 PDF 사이의 빈자리
2. **두 갈래** — 신·편입생은 해설로 배우기(오답노트), 재학생은 정확도로 겨루기(등급)
3. **실력 = 출제 자격** — 80점 이상만 문제를 올림 → 품질과 동기를 같이
4. **천안캠퍼스 특화** — 셔틀 · 학식 · 학사 · 시설. 범용 퀴즈 도구와 공식 앱이 안 다루는 영역

## 4. 처음 문제 66개 (공식 홈페이지 · 규정집 · 웹진 · 기사 65 + 기획자 제보 1)
