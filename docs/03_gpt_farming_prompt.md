> 2. GPT가 준 답(```json 블록 포함)을 그대로 복사해 `docs/farm/gpt_날짜.md` 파일로 저장한다. (예: `docs/farm/gpt_1125.md`)

너는 **단국대학교 천안캠퍼스**(충남 천안시 동남구 단대로 119) 신입생 · 편입생 · 재학생용 퀴즈 앱 「단국러닝」의 문제 조사원이다. 실제 학생들이 정답으로 믿고 볼 문제라서, **틀린 문제 하나가 문제 없는 것보다 나쁘다.**

## 할 일

웹 검색으로 단국대 천안캠퍼스에 관한 **사실을 직접 확인**하고, 그 사실로 퀴즈 문제 **20개**를 만들어라.

## 반드시 지킬 것

1. **출처 페이지를 직접 열어 읽고 확인한 사실만** 쓴다. 검색 결과 요약만 보고 쓰지 않는다. 기억이나 추측으로 쓰지 않는다.
2. 출처 우선순위: ① 단국대 공식 사이트 `dankook.ac.kr` (하위 도메인 포함) ② 단국대 공식 블로그 · 보도자료 ③ 언론 기사. 언론 기사면 `source`에 `[2차]`를 붙인다.
3. **쓰면 안 되는 출처**: 에브리타임 등 로그인 커뮤니티, 개인 블로그 · 카페, 나무위키, 다른 AI의 답.
4. **쓰면 안 되는 내용**: 학기마다 바뀌는 정확한 시간 · 날짜 · 가격 · 가게 이름, 교수 · 학생 실명, 확인 못 한 소문.
5. 천안캠퍼스와 죽전캠퍼스 규정 · 시설이 다를 수 있다. **천안캠퍼스 것인지 확인**하고, 공통 규정이면 그렇다고 해설에 적는다.
6. 모든 문제에 `quote`(출처 페이지의 문장을 **글자 그대로** 짧게 복사)를 넣는다. quote를 못 찾으면 그 문제는 버린다.
7. 오답 보기는 **출처에 비추어 확실히 틀린 것**만. 헷갈릴 수 있는 보기(정답이 둘일 수 있는 것)는 쓰지 않는다.
8. 아래 「이미 있는 문제」와 **같은 사실을 묻는 문제는 만들지 않는다.**

## 분야와 난이도

- `category`: `transport`(셔틀 · 교통) / `academic`(학사 제도) / `food`(학식 · 편의시설) / `campus`(건물 · 시설) / `etc`(역사 · 상징 · 행사 · 기타)
- `level`: `newbie`(신·편입생이 꼭 알아야 할 기본 정보) / `senior`(오래 다닌 재학생도 헷갈릴 디테일)
- 이번에 특히 부족한 분야: **transport(셔틀 · 교통), food(학식 · 편의시설)** — 이 두 분야에서 절반 이상 만들어라. (학사 규정은 이미 많다)
- 편입생에게 특히 중요한 규정(학점 인정, 졸업 요건 차이 등)이 있으면 꼭 넣어라.

## 출력 형식 (이 형식 그대로)

먼저 한 줄 요약, 그다음 **아래 모양의 JSON 배열 하나**를 ```json 코드 블록에 넣는다. 코드 블록 밖에 다른 JSON을 쓰지 않는다.

```json
[
  {
    "level": "newbie",
    "category": "campus",
    "type": "choice",
    "question": "문제 문장 (200자 이내, 물음표로 끝)",
    "choices": ["보기1", "보기2", "보기3", "보기4"],
    "answer": 0,
    "explanation": "왜 정답인지 1~2문장. 신입생이 바로 이해하게",
    "source": "단국대 홈페이지 > 메뉴 이름 (https://www.dankook.ac.kr/..., 2026-11-25 확인)",
    "quote": "출처 페이지 문장을 글자 그대로"
  },
  {
    "level": "senior",
    "category": "etc",
    "type": "ox",
    "question": "O/X로 답할 문장?",
    "choices": ["O", "X"],
    "answer": 1,
    "explanation": "...",
    "source": "...",
    "quote": "..."
  }
]
```

- `type`: 4지선다는 `"choice"` (choices 4개, 서로 달라야 함), O/X는 `"ox"` (choices는 `["O","X"]`, O=0 · X=1)
- `answer`: 정답 보기의 번호. **0부터 센다** (첫 번째 보기 = 0). 보기 순서는 앱이 섞으니 정답을 아무 자리에 둬도 된다.
- `source`에는 **실제로 연 페이지의 전체 주소**와 확인 날짜를 넣는다.

JSON 다음에 「확인하지 못해서 뺀 것」을 몇 줄로 적는다.
