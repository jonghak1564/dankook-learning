# 디자인 시스템

팀프로젝트(테크브리프)에서 가져온 디자인 토큰과 기본 부품입니다.

- 토큰: [LG UI Kit 디자인 토큰](https://github.com/enovaui/design-tokens) (`@enovaui/web-tokens` 3.8.0, Apache-2.0) 기반 `src/tokens.css`
- 글꼴: Pretendard (SIL OFL)
- 부품: `src/ui/index.jsx`

내 프로젝트 색을 바꾸려면 `src/tokens.css`의 `--tb-*` 값만 바꿉니다.
